Masaru - a Knytt Stories level by KathAndSunny
===============================================

HOW TO PLAY
  1. Unzip this folder anywhere.
  2. Run "Knytt Stories Plus 1080.exe".
  3. Select "Masaru" (by KathAndSunny) from the level list.
  4. Pick a save slot, then click "Start New Game".

CONTROLS  (keyboard defaults - rebind from main menu > Set Controls)
  Left / Right ....... Walk
  X (hold) ........... Run
  Z .................. Jump  (press again in mid-air = Double Jump)
  Up (hold) .......... Climb (against a climbable wall)
  Shift (hold) ....... Umbrella - glide down slowly
  Esc ................ Pause / menu

  This level starts you with Run, Climb and Double Jump unlocked.
